# Contributing
- Branches: `feature/*` off `main`; one PR per feature or milestone step.
- Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `test:`, `perf:`).
- Code and docs in English. Format with `clang-format` (C++) before committing.
- Only permissively licensed dependencies; record them in `THIRD_PARTY.md`.
- Never commit keystores, tokens or `local.properties`.
